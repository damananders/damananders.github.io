Ask the Helper. It does the fiddly bits.

Describe what you want in plain words and the Helper makes the change for you, using the same buttons and files you can see. It can also read a web page you point it at.

  • Offline with a free local model through Ollama, on your own graphics card.
  • Online with your own API key, kept in Windows Credential Manager.
  • It works inside your site’s folder only, and asks before running anything.
  • It can never put your site online by itself. Only you can.

Publishing that can’t surprise you.

  1. PreviewSee every change on a private preview that only your PC can open.
  2. SyncIt fetches the latest version of your site first, so nobody’s work is overwritten.
  3. CheckA scan stops passwords and keys from slipping into what you publish.
  4. ConfirmGoing straight to your live site means typing PUBLISH. A review copy (pull request) is the default.
  5. UndoLocal snapshots and history mean any change can be rolled back. It never force-overwrites.

Only the owner can change a site.

Owners only

Before any edit goes online, it checks your GitHub account can actually push to that site. If not, it opens in view-only mode.

Any site to learn from

Type someone else’s address and you get a local copy to study and experiment with. It can’t publish to their real site.

Keys stay locked

Sign-ins go through Git Credential Manager, and API keys live in Windows Credential Manager, never in plain files.

Nothing phones home

No telemetry, no accounts with us. The preview runs on your own PC only.

Questions

Do I need to know how to code?

No. Easy mode is made for people who never want to see code. Pro mode is there if you do.

Which websites does it work with?

Sites kept on GitHub, like GitHub Pages sites, are the best fit: type the address and it finds the repository for you. You can open any public address to study a local copy, but you can only publish to sites you own.

Can the Helper break my site?

It only works inside your site’s folder, asks before running commands, and can’t publish. Every change shows in the preview first, and Undo is always there.

Is it free? Where is the source?

Yes, it’s free under the MIT licence. Releases are published on GitHub; the source code isn’t public for now.

Does it work on Mac or Linux?

Not yet. It’s Windows only for now.

How do I remove it?

Delete the folder you unzipped. Your sites stay where they are on your PC and on GitHub.

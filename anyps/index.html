AnyPS

One launcher for six generations of PlayStation emulation. Plug in a controller, point it at your own games, and play from the couch without touching a mouse.

  • Six systems, one shelf — PS1, PS2, PSP, PS Vita, PS3 and PS4 games side by side, powered by the open-source DuckStation, PCSX2, PPSSPP, Vita3K, RPCS3 and shadPS4 projects.
  • Controller first — DualSense, DualShock and Xbox pads work out of the box, including in every settings screen.
  • Settings without leaving — tweak each emulator, globally or per game, from inside the launcher.
  • Guided first boot — a simple, kid-friendly setup walks you through adding your games and firmware.
  • Motion helper — stick-driven tilt and shake for games that expect a gyro.
  • Mass install, cheats, online — one-button install of a whole PS3/PS4 library, a cheats manager for every system, and PS3 online (RPCN) accounts created right inside AnyPS.
  • Memory tools, save vault, smart lists — find and freeze values in a running game, roll saves back in time, and browse by Unplayed / In progress / Finished / Franchise.
  • No seams — a launch screen until the game is really playing, emulator pop-ups answered for you, and a crash guard that reverts bad settings.
  • Keeps itself current — AnyPS checks this page and updates itself in place.

    Getting started

    1. Download and unzip the release.
    2. Run AnyPS.exe and follow the first-boot setup.
    3. Drop console files dumped from hardware you own into AnyPS\System\<console>.
    4. Put your own game backups in AnyPS\Games\<console>.
    No games, BIOS or firmware are included, and none are provided here or on request. AnyPS is a front end; please only use content you legally own.

    AnyPS V1.04: complete feature list

    One launcher (AnyPS.exe) that boots straight into a console-style interface and plays PlayStation games across six systems (PS1, PS2, PSP, PS Vita, PS3, PS4), each in its own emulator, without ever leaving the app. Self-contained and shareable; you supply the games and the console system files.

    1. The app itself

    • Single executable. One AnyPS.exe launches everything; no installer, no separate windows to manage.
    • Boots like a console. Cold-boot chime and animation, then straight to the system picker.
    • Random look on boot. The background colors AND the moving shapes re-roll each launch: ribbons, floating circles, rolling squares, rising bubbles, a starfield or drifting hexagons (or pin one).
    • Boot options. Skip the intro animation; boot chime on/off.
    • Smooth fades when switching between systems.
    • Custom exe icon. "AnyPS" wordmark on a grey→silver→PlayStation-blue badge, built in at every size.
    • Start with Windows (console mode). Optional — AnyPS launches at sign-in.
    • Runs windowed, never exclusive fullscreen. Every emulator is forced to borderless windowed so alt-tab and overlays behave.
    • Keeps emulator windows on AnyPS's monitor (handles multi-monitor setups automatically).
    • Close with Alt+F4, or ○ / Esc on the system picker brings up an "Are you certain?" exit confirm.

    3. Console-native interface

    • System picker with hand-drawn console silhouettes (AnyPS's own art), each showing its emulator and game count.
    • PS1/PS2/PSP/Vita/PS3 use an XMB-style lane (System / Settings / Photo / Game categories) built from your PS3 system software — real Rodin fonts, original category icons, menu sounds, and the coldboot sound.
    • PS4 uses a PS4-style home row of tiles.
    • Theme-matched waves and colors per system.
    • Rounded corners throughout (game art, tiles, menu bars, photo viewer).

    4. Game library

    • Self-contained layout: games live in AnyPS\Games\<console> (PS1, PS2, PSP, Vita, PS3, PS4).
    • Broad format support: PS1 cue+bin / chd / pbp / m3u / folders; PS2 iso / chd / cso; PSP iso / cso; Vita .vpk / .zip / dumped folders + .pkg with zRIF; PS3 game folders (PS3_GAME) + PKG updates/DLC; PS4 PKG tiles or unpacked folders.
    • Box art from each game's own icon, with an online cover fallback (retro covers + GameTDB for PS3/PS4) and custom covers.
    • Title music from each game (SND0), with an on/off switch.
    • Multiple library roots supported via AnyPS.ini.

    5. Browsing & organizing games

    • Sort (□ / X button, or F): Default, A-Z, Most played, Recently played, Never played.
    • Box-art grid view as an alternative to the rows: big covers, six across, scrolls by row (any game's △ menu ▸ Game list style, or AnyPS Settings).
    • Search all games across every console at once (AnyPS Settings).
    • Only show games likely to run filter (uses your ratings and the emulators' compatibility lists; handy for PS4).
    • Find duplicate games: the same title in several regions/versions, with one-press hide for the extras.
    • Search (△ Options ▸ Search games…) filters the list by name; Clear search to reset.
    • Favorites (△ ▸ Add to favorites): pinned to the top with a ★, and shown in a "Favorites & recent" row on the picker.
    • Continue (□ on the picker): instantly boots your last-played game.
    • Recently played row on the picker with play-time captions.
    • Game count shown under each console.
    • Rescan games (△ menu): picks up newly added games without restarting.
    • Rename a game's display title.
    • Custom cover: pick one of your screenshots, or drop a cover.png in the game's folder.
    • Hide a game (and unhide later in AnyPS Settings ▸ Hidden games).

    6. In-game home menu (pause overlay)

    Opened by the PS/Guide button, holding Share/View, or Ctrl+Shift+Q:

    • Resume / Quit game.
    • This game's settings (per-game emulator config).
    • Information page: title, ID, version, add-ons, disc list, trophy progress (earned/total), play time, launch count, folder.
    • Change Disc for multi-disc PS1 games, with automatic disc change.
    • Saves / Memory Cards and Trophies for the current game.
    • Motion mode toggle (PS3/PS4).
    • Save states (PS1/PS2/PSP/PS3): save to a slot, load, list, delete; auto-checkpoints and rewind.
    • Speed (PS1/PS2/PSP): fast-forward on/off, rewind.
    • Enhancements (PS1/PS2/PSP): graphics quality (performance/balanced/quality), cheats on/off, and Cheats for this game (the cheats manager, below).

    7. Save data

    • Per-game saves browser: PSP SAVEDATA, Vita Saved Data, PS1/PS2 memory cards (with editors), PS3/PS4 savedata, with details and timestamps.
    • Back up any save or memory card.
    • Restore a save or memory card from a backup.
    • Export all saves + screenshots to a USB stick (or AnyPS\Export).
    • Open the backups / export folders in Explorer.
    • Automatic save backup on a schedule (daily or weekly), exporting saves and screenshots.
    • Save-state manager: every save state on disk per console, with dates, and delete.

    8. Trophies & achievements

    • PS3 trophies read from RPCS3 (TROPCONF / TROPUSR): per-set lists, grades, locked/hidden, earned counts.
    • PS4 trophies read from shadPS4 (TROP.XML). Vita trophies read from Vita3K (TROP.SFM / TROPUSR.DAT).
    • RetroAchievements for PS1/PS2/PSP — labelled "Trophies" for consistency — with in-app sign-in (you type the password; only the token is stored).
    • RetroAchievements for PS3 too: PS3 games without a Sony trophy set show their RetroAchievements set, with a friendly two-step Web API key card.
    • Unlock toasts while playing, and a Recent trophies & achievements page.
    • Hardcore mode supported where the emulator offers it.

    9. Settings — native and full

    • Console-native settings screens per system (PS1 System Config, PS2 Browser, PSP System Settings, Vita System Configuration, PS3 XMB settings columns, PS4 Settings) — the familiar menus.
    • Real BIOS shells: PS1 System Menu and PS2 Browser (memory cards, clock, language).
    • Full emulator settings for every emulator, all from inside AnyPS (DuckStation, PCSX2, PPSSPP, Vita3K, RPCS3, shadPS4, RPCS4) — curated, borderless-locked.
    • Per-game settings for every system.
    • Everything is editable without leaving the app.

    10. Themes & personalization

    • PS3 .p3t themes — install and apply, with wallpaper and icons.
    • PS4 theme options.
    • Random boot colors (toggle + "new colors now").
    • Your own wallpaper from any screenshot.

    11. Controllers & input

    • Keyboard-first menus that also fully support a gamepad (SDL2 with XInput fallback, background input).
    • Controller-aware button glyphs: PlayStation glyphs on a PS pad, Xbox face buttons on an Xbox pad, switched live.
    • Controller battery shown in the status line.
    • Quit combo: hold Share/View + Options/Start.
    • Motion bridge: L3 + R3 turns the right stick into a motion sensor (hold L3 to shake) so Xbox/stick-only pads can play gyro sequences — for RPCS3 and shadPS4. Adjustable sensitivity.

    12. Multi-disc

    • Multi-disc PS1 games (e.g. Legend of Dragoon) merge into one entry; discs swap automatically, with a manual "Change Disc" in the home menu.

    13. Updates

    • AnyPS updates itself: AnyPS Settings ▸ AnyPS version checks this website, shows installed vs newest, and “Download and install” swaps in the new build and restarts — games, saves and settings untouched.
    • System Software Update panel updates each emulator in place (with backups).
    • Reset a console's settings back to how AnyPS first set it up.
    • Boot-time update check (optional, on by default): a quiet toast if an emulator has a newer build.

    14. Screenshots & gallery

    • Set any screenshot as a game cover or the wallpaper.
    • Favorite screenshots: press □ on a photo to star it; a Favorite screenshots page collects them.
    • Idle screensaver / attract mode: leave a menu alone and AnyPS drifts through your games' art and music; any button returns.

    15. Users / profiles

    • PS3 users: switch, rename, create. PS4 players. On-screen keyboard with masking.
    • PSP nickname.

    16. Play stats

    • Play time and launch counts tracked per game.
    • Play time / most played page (ranked, with total hours).

    17. Accessibility & help

    • Text size (Normal / Large) and High contrast mode.
    • Menu sound effects and game music on/off.
    • Help screen: controls reference, how to add games, and the one-time console-file setup.
    • Rebuilt on-screen keyboard: a clean grid with a cursor; LT = Shift, RT = Done, LB/RB move the cursor, □ Backspace, △ Space, LT+△ = symbols page, numbers row.

    18. Setup & sharing

    • Step-by-step set-up wizard: one step per console (PS1, PS2, PS3, Vita, checklist) telling you what the file is and where it comes from, with “Pick the file…”, an auto-search of Downloads/Desktop/Documents, and drag-and-drop onto the AnyPS window — BIOS and PS3UPDAT.PUP install themselves, game files and .pkg are filed into the right Games folder. AnyPS then builds the PlayStation look from your own system software.
    • "READ ME FIRST" guidance written on first run.
    • Shareable release (make_release.ps1): a clean copy with the launcher, all emulators and tools — no games, no BIOS/firmware, no Sony artwork or sounds (the look is rebuilt on each player's PC from their own files).
    • Designed so a child who can only download and run an exe can set it up.

    19. Package handling (behind the scenes)

    • PS3: installs game, then updates, then DLC on first launch (with .rap licences), driven automatically; base disc registered first.
    • PS4: unpacks .pkg tiles (game / update / DLC) into the library; patches the DLC-loader stub so games with add-ons boot.

    20. User Profiles

    • Up to 10 player profiles, each with a name, an avatar (12 colors or any screenshot), and an optional 4-digit passcode — just like a PS3/PS4.
    • A “Who's playing?” sign-in screen, reached from a smiley Profile badge in the top bar of the console picker (press Up, or click it).
    • “Create New User Profile” tile; Triangle opens “Modify User Profile” (rename / picture / passcode); Square deletes with a confirmation.
    • Each profile keeps its OWN play time, favorites, game names, trophies, AND save games (save data is redirected per profile, so switching players swaps saves and nothing is shared by accident). The first profile you make inherits your existing saves — they are moved in, never deleted.
    • Unified “Trophies & achievements” page per profile, pooling PlayStation 3, PlayStation 4 and RetroAchievements totals in one place.
    • Profile stats page: total play time, games played, most played, favorite console, launches.
    • Guest profile (temporary, wiped on sign-out or close), avatar from any image file, and export / import a whole profile as one .zip to move it to another PC.

    21. Collections

    • Make your own game folders (Settings > Collections, or a game's Triangle menu > Collections).
    • Automatic “Most Played Games” folder: any game you play 10+ hours collects here on its own, sorted most-played first.

    22. Tutorials

    • First-time, on-screen tips on the system picker, in a game list, and the first time you open the in-game overlay.
    • A per-game “How to play” card (shown the first time you launch each game, and in its Triangle menu) with the controls and an editable walkthrough you can fill in yourself.
    • Every tutorial has “Turn off all tutorials”; switch them back on or replay them all from Settings > Tutorials.

    23. Controller Remap (Visual)

    • A visual controller screen (Settings > Remap controller buttons): rebind any button from a live pad diagram, with quick presets (Standard, Swap Cross/Circle, Nintendo layout).
    • Writes your layout straight into PS1, PS2, PSP, Vita and PS3, with automatic backups and a Reset to default. (PS4 keeps its own controller settings.)
    • Per-game layouts: a game's △ menu ▸ Controller layout for this game gives that one game its own buttons; AnyPS writes them when the game starts and restores your usual layout when it ends.

    24. Online / Netplay

    • PS3 online (RPCN) without leaving AnyPS: AnyPS speaks RPCN's own protocol, so creating the free account (username, e-mail, password), entering the e-mailed code, checking the sign-in and resending the code all happen in AnyPS. “I already have an account” too.
    • “Would you like to enable Netplay?” the first time you start a PS3 game: Yes sets it up on the spot, No opens the PS3 network settings.
    • PSP ad-hoc Wi-Fi in one tap: networking on and the busiest public server joined. A “Finding PSP players” card gives the 3 rules, the Discords, and a “fresh network ID” button for two PCs that can't see each other. (PS1, PS2 and PS4 have no usable built-in online.)

    25. Game Compatibility Flags

    • Rate how well each game runs (Boots / Playable / Has issues / Runs perfectly) from its Triangle menu; the rating shows on the game's tile.
    • PlayStation 3 games auto-fill their rating from RPCS3's official compatibility list. Your own rating always overrides it.

    26. Game Backgrounds, Music & Video

    • Highlighting a game now shows its full-screen background: the real built-in art on PS3/PS4/PSP, and the box art for PS1/PS2 games that have no background image — so every game shows something.
    • Theme music plays on highlight for games that include it (PS3/PS4).
    • Optional looping background VIDEO: drop a “background.mp4” in a game's folder, or set one from the game's Triangle menu.

    • Import games from a folder (PS1/PS2/PSP): pick a folder of disc images and AnyPS files them in, one folder per game.
    • Folder watcher: drop games into Games\<console> while AnyPS is open and the list refreshes itself.
    • About PS4 support: an honest first-open card on what works, what doesn't, and how to follow the shadPS4 project.

    30. Smoother everyday use

    31. Cheats Manager

    • Any game's △ menu ▸ Cheats (also in the in-game overlay). Each system in its own format, switched with one press.
    • PS1 — pulls the game's entry out of DuckStation's built-in cheat database and lists every cheat; ticked ones are written to the game's settings.
    • PS2 — lists your .pnach cheat files for the game and toggles them.
    • PSP — lists the cheats in the game's CWCheat file and toggles them (can create the file for you).
    • PS3 — lists the community game patches for your title (60 FPS, unlocks, fixes) and toggles them by version.
    • PS4 — shows the cheat files shadPS4 has downloaded for the game (switching them on happens in shadPS4's own window).
    • Vita — VitaCheat .psv codes per game, one press each, with a community database download.
    • Your own cheats found with the Memory tools (PS3 / PS2 / PSP / Vita) live beside these and switch on from the same page.

    New Features

    PlayStation Vita joins the shelf

    • A seventh console card between PSP and PS3, powered by the open-source Vita3K project — with everything the other lanes have, so it never feels like the odd one out.
    • Games: drop a .vpk, a .zip, or a dumped game folder (NoNpDRM) into Games\Vita. Dumps are linked into Vita3K, not copied; .vpk files are unpacked; the dump's licence (work.bin) is put where Vita3K reads it, automatically.
    • Updates and add-ons: a patch\ or addcont\ folder beside the game, or .pkg packages with their zRIF key (a KEY.txt next to the file). Vita3K installs packages headless; “Install all waiting games and add-ons” does the whole folder in one press.
    • Set-up: the system software (PSVUPDAT.PUP) installs itself from a drag-and-drop, the file picker, or the auto-search — no Vita3K window, ever. The font pack (PSP2UPDAT.PUP) is optional and handled the same way.
    • Vita settings screen in plain language: resolution multiplier, filters, FSR, V-Sync, renderer, accuracy, sound, language, buttons, PS TV mode, motion, LiveArea, cheats, texture packs, screenshot key, online. Quick presets: Smooth / Sharp / Safe.
    • Real Vita trophies (TROP.SFM / TROPUSR.DAT) in the Trophies page and the game's Information card.
    • Saves: Saved Data browser, back up / restore, the save vault, save sync and per-profile saves all cover the Vita.
    • Cheats: VitaCheat-format .psv files per game, each code switched with one press, “Get this game's codes from the community database”, add your own.
    • Memory tools & cheats work inside Vita games too (AnyPS reads the emulator's own memory block).
    • Screenshots (F12) in the Photo column, texture packs, crash guard, play-time, smart lists, franchises, rewards, controller remap — all wired for the Vita.
    • Nothing of Vita3K's own interface shows unless you open it yourself from Behind the curtain.

    Memory tools & a bigger cheats story

    • Memory tools & cheats in the in-game overlay for PS3, PS2, PSP and Vita: search a value (1/2/4 bytes), narrow it, set it, freeze it, watch it, and save it as a named cheat that AnyPS re-applies every launch of that game.
    • Value watch window and a pattern finder for re-finding an address after a reload.
    • PSP community cheat database (cheat.db) download with per-game seeding; Vita community database per title; export / import cheats as a zip to share with another AnyPS player.

    Save states, checkpoints, rewind

    • Save states from the overlay on PS1, PS2, PSP and PS3: save to a slot, load, see every state with dates, delete. (Vita3K and shadPS4 have no save states; the overlay says so honestly.)
    • Auto-checkpoints: a state every N minutes (your choice) so “Go back in time” can rewind a bad decision.
    • Continue loads the newest state; Save a state, then quit; optional “Quit always saves a state first”.

    No seams

    • Launch screen: AnyPS stays in front with the game's art until the emulator is really playing (RPCS3's shader-compiling wait included), then hands off cleanly.
    • Dialog sweeper: any emulator pop-up is read, answered and logged for you; you get an AnyPS toast instead. Emulator on-screen messages, hints and overlays are switched off.
    • Crash guard: a game that dies within a minute gets a “That didn't go well” card — revert to the last-known-good settings, restart, or save a report zip. Games that ran 30 minutes without a fatal error earn a ✓ Verified badge.
    • Restart the game now from the overlay to apply changed settings straight away; Quit and play the next from your Play next queue.

    Saves: vault and sync

    • Save vault: rolling snapshots of a game's saves every N minutes and at quit, keep N, restore any from the game's △ menu or the overlay.
    • Save sync between two PCs through any synced folder (OneDrive, Drive, Dropbox, NAS, USB) or WebDAV (Nextcloud); off by default.
    • PS1 memory-card editor: list, export, import and delete individual saves. PS2 memory-card editor: the 8 MB card as a file system — titles, export .psu, import .psu, delete.
    • Memory-card swap per game (PS1 per-game vs shared card, PS2 slot 1/2) with restart-now.

    Library, lists and hubs

    • Smart lists: Unplayed, In progress, Finished, Local co-op, Verified, Quick sessions, Long haul, Added this week, Favorites — each one yours to show or hide; mark games Finished or Co-op from their △ menu.
    • Franchise hubs: series across consoles, oldest first, automatic by title with a per-game override.

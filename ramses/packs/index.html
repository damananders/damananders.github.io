Shared skills and knowledge

Packs are plain text: playbooks Ramses follows (skills) or notes it can search (knowledge). Nothing in a pack can run. Install one from Ramses: Settings, Connections, Share packs, Browse the pack gallery. Ramses checks each download against the SHA-256 listed here.

Share a pack of your own

  1. In Ramses, open Settings, Connections, Share packs, and save your skills or a knowledge pack as a file. Secrets are removed on the way out, but read it first: notes about you are not.
  2. Open an issue on the Ramses GitHub page with the file attached and a line on what it is for.
  3. Once it has been read through, it is added here with its checksum.
